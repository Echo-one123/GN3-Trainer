# GN3 Trainer

Exam trainer for the EAL / City & Guilds Initial Verification exam, built on IET Guidance Note 3 (9th edition): GN3-order exams on the EAL learning-outcome split, three mock papers, calculation practice (R1 + R2, rings, Zs, insulation resistance, PFC, electrodes), flashcards, a find-it drill, Daily 10, an exam countdown and a strong/weak progress tracker.

Open it at **https://echo-one123.github.io/GN3-Trainer/**. On an iPhone, open it in Safari, then Share → Add to Home Screen.

Progress is saved on the device you use.
